# 日语口语教练（PWA）

每天 1 小时、26 周的日语口语训练 App。可以在手机浏览器里“添加到主屏幕”，像普通 App 一样使用。

## 功能
- **分级测试**：分自评、自适应笔试/听力（5 级，每级 4 题，答对 3 题升级）、AI 口语测试三部分，综合确定起点。
- **26 周课程**：按起点从 32 个单元中排课，单元用完后接实战主题。每周 6 节课加 1 次口语测评。
- **每天 60 分钟**：间隔复习 → 今日句型 → 影子跟读（语音识别打分） → AI 情景对话（实时纠错） → 纠错总结。水平越高，对话时间越长。
- **间隔复习**：看中文说日语，按 SM-2 简化算法安排复习。对话中说错的句子会自动变成卡片。
- **离线**：假名训练和复习卡片不联网也能用。课程生成和 AI 对话需要联网和 Claude API Key。

## 在电脑上运行
```bash
python -m http.server 8765 --directory nihongo-coach
```
然后打开 http://localhost:8765

## 装到手机上（推荐用 GitHub Pages，免费）
麦克风和“添加到主屏幕”都要求 HTTPS，所以需要部署到一个 HTTPS 网址：
1. 在 GitHub 新建一个仓库，把 `nihongo-coach` 文件夹里的所有文件上传到仓库根目录。
2. 进入仓库 Settings → Pages，Source 选 `main` 分支、`/ (root)`，保存。
3. 一两分钟后会得到一个网址 `https://<用户名>.github.io/<仓库名>/`。
4. 用手机打开这个网址：
   - **Android**：用 Chrome 打开 → 菜单 → “添加到主屏幕 / 安装应用”
   - **iPhone**：用 Safari 打开 → 分享 → “添加到主屏幕”
5. 第一次打开时，在欢迎页或设置里填写 Claude API Key（从 console.anthropic.com 获取）。

Netlify、Vercel、Cloudflare Pages 也可以，把文件夹拖进去即可。

## 注意
- API Key 只保存在手机浏览器的本地存储里，由浏览器直接请求 Anthropic API。请不要把 Key 写进代码或上传到仓库。
- 换手机前，先在「设置」→「导出数据」备份学习进度。
- 语音朗读用的是系统自带的日语语音。如果没有声音，在系统设置里安装日语语音包。
- 费用大致估算：用 Opus 5.5，每天一节课（生成课程 + 约 15 轮对话 + 总结）大约 0.1–0.3 美元。改用 Sonnet 5.5 大约便宜一半。

## 文件结构
- `js/data.js`：等级、测试题库、假名表、课程大纲、每日时间分配
- `js/store.js`：本地存储、课程进度、间隔复习算法
- `js/ai.js`：Claude API（课程生成、对话陪练、复盘、口语评估）
- `js/speech.js`：日语朗读、语音识别、发音相似度
- `js/app.js`：各个页面和学习流程
